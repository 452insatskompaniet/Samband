# Samband version 1.0 – så lägger du ut det

1. Skapa ett nytt repo som heter **Samband** i kompaniets GitHub.
2. Ladda upp de 5 filerna: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` (LASMIG.md behöver inte med).
3. Settings → Pages → Deploy from a branch → main / root.
4. Öppna adressen på telefonen och välj "Lägg till på startskärmen" (i Edge: menyn → Lägg till telefon).

Nytt i 1.0: appen heter Samband, har Admins färger och en gul ikon med svart Hv-logga. Funktionen är oförändrad. Ny adress betyder att alla börjar på noll (PIN, nyckel och arkiv följer inte med från Samband 452).
